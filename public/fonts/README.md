# Manrope

Original variable WOFF2 files from `@fontsource-variable/manrope` 5.3.0, copied without modification. Weights 200–800, normal style; Latin, Latin Extended, Cyrillic and Cyrillic Extended subsets. Latin Extended includes the tenge currency sign (U+20B8).

The SIL Open Font License is included in [Manrope-OFL.txt](Manrope-OFL.txt). Subset ranges and font-display: swap are declared in `app/fonts.css`. Files are served from this repository; installation, build and rendering do not contact Google Fonts. The font npm package is no longer needed.
