## Фактически выполненные проверки

Для каждого из первых четырёх коммитов точное дерево индекса экспортировано
в отдельную временную копию. В каждой выполнены `npm run lint` и `npm run build`:
все восемь запусков завершились с кодом 0. Проверки не подменялись запуском
целого ещё не разделённого рабочего дерева.

Production-сборка четвёртого коммита проверена в headless Chromium:

- Ширины 1920, 1440, 1024, 768 и 390 px: нет горизонтального переполнения страницы,
  проверенных пересечений текста/иллюстраций и цены/таймера, ошибок JavaScript
  и ссылок на отсутствующие секции. На телефоне лента прокручивается.
- Сортировка по цене, раскрытие восьми результатов и возврат к пяти работают.
  Отдельная проверка данных подтвердила порядок всех пяти режимов сортировки
  и отсутствие изменения исходного массива.
- Ввод остаётся черновиком до отправки; поиск по адресу «Достык» и району
  «Сарыаркинский» даёт ожидаемые предложения. Сброс очищает строку и фильтры.
- Детали содержат адрес, оба срока самовывоза, аллергены и сообщение о недоступности
  покупки. Даты проверены отдельно при переходе через полночь в `Asia/Almaty`.
- Избранное сохраняется после перезагрузки и фильтруется. Таймер меняется каждую секунду.
- Escape возвращает фокус к карточке; ссылка из сообщения для заведений переводит
  фокус на заголовок объяснения сервиса. Партнёрской формы и автоматического диалога нет.
- Axe с тегами WCAG 2 A/AA и WCAG 2.1 AA не обнаружил нарушений в проверенном
  состоянии страницы. Это автоматическая проверка, а не полная сертификация доступности.

Локальные снимки и метрики находятся в `.impeccable/review/commit-split/`;
они исключены из Git. Временные журналы отдельных проверок и резервная копия
исходного рабочего дерева — в `/private/tmp/damtap-history/` (не постоянное хранилище).

## Ограничения и доказательства

Реального backend-подключения, авторизации, заказов, оплаты, бронирования и отправки
заявок эта работа не добавляет. Серверная часть Spring Boot / PostgreSQL — отдельный
вклад другого участника и пока не интегрирована. Адреса, наличие и цены моковые.

Коммиты подготовлены локально, без push и тега `prob-period-1`. После разрешённой
публикации для YouTrack можно приложить ссылки на эти SHA в репозитории
`commedeschamps/DamTap`. До публикации доказательства доступны через:

```bash
git log --reverse --format='%h %an <%ae> %s' 0eca6c3..main
git show --stat <sha>
git diff 0eca6c3..main -- components app README.md PRODUCT.md DESIGN.md docs
```
