These are editable PlantUML source files. For **readable diagrams rendered directly in GitHub**, open [../07-architecture.md](../07-architecture.md), which embeds equivalent Mermaid diagrams. PlantUML users can export SVG/PNG with: plantuml -tsvg system-context.puml use-case.puml component.puml . No SVG/PNG exports are claimed to have been generated in this commit.

Solid arrows and unlabeled functions describe the tagged implementation; dashed arrows and explicit "(planned)" labels describe intended future components.
