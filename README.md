# DamTap

DamTap — маркетплейс еды по выгодным ценам в Астане. Находите блюда по вкусу,
сохраняйте любимое и помогайте сокращать пищевые отходы.

Интерфейс на русском языке: поиск по блюдам, заведениям, районам и адресам,
категории, сортировка предложений, карточки с деталями самовывоза и избранное. Фирменный знак Fork in D — тёмно-бирюзовая D с белой трёхзубой вилкой и зелёным листом; используется точный предоставленный логотип с надписью DamTap.

## Разработка

Next.js App Router, React, TypeScript, Tailwind CSS v4. Основной шрифт — Manrope.

```bash
npm install
npm run dev
npm run lint
npm test
npm run build
npm start
```

Для сборки используется Webpack. Manrope включён в репозиторий в `public/fonts`; сборка не скачивает шрифты и не требует Google Fonts. Карта загружает стиль и тайлы OpenFreeMap при открытии.

Правила оформления и использования логотипа — в [DESIGN.md](DESIGN.md).
Границы текущей реализации — в [PRODUCT.md](PRODUCT.md).

## Бэкенд

Spring Boot API находится в `backend/`. Требуется Java 17 или новее.

```bash
cd backend
./mvnw test
./mvnw spring-boot:run
```

По умолчанию API слушает `127.0.0.1:8080`, данные сохраняются в H2
(`backend/data/` при запуске из `backend/`). Настройки: `DB_URL`, `DB_USER`,
`DB_PASSWORD`, `PORT`, `SERVER_ADDRESS`, `SEED_DEMO`, `ADMIN_API_KEY`.

Текущий фронтенд использует моковые данные и ещё не подключён к этому API.
Авторизация, покупка, бронирование и отправка партнёрских заявок через интерфейс
недоступны.
