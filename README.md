# DamTap

Фронтенд MVP платформы продажи остатков еды со скидкой в Астане.

## Запуск

```bash
npm install
npm run dev
```

Проверки: `npm run lint`, `npm run build`. Запуск production-сборки: `npm start`.

Добавьте макет в `design/mockup.png`, а изображения блюд — в
`public/images/food-1.webp` … `public/images/food-8.webp`.

Моковые предложения находятся в `data/offers.ts`. Сроки предложений вычисляются
при загрузке модуля; цены указаны в тенге.
