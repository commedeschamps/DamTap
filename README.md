# DamTap

DamTap — маркетплейс еды по выгодным ценам в Астане. Находите блюда по вкусу,
сохраняйте любимое и помогайте сокращать пищевые отходы.

Интерфейс на русском языке: поиск по блюдам, заведениям, районам и адресам,
категории, сортировка предложений, карточки с деталями самовывоза и избранное. Фирменный знак D Plate Mark объединяет букву D и тарелку.

## Разработка

Next.js App Router, React, TypeScript, Tailwind CSS v4. Основной шрифт — Manrope.

```bash
npm install
npm run dev
npm run lint
npm run build
npm start
```

Для сборки используется Webpack. При первой сборке нужен доступ к Google Fonts.

Правила оформления и использования логотипа — в [DESIGN.md](DESIGN.md).
Границы текущей реализации — в [PRODUCT.md](PRODUCT.md).
Состав локальной доработки, история и выполненные проверки —
в [docs/REFINEMENT_REPORT.md](docs/REFINEMENT_REPORT.md).

Фронтенд использует моковые данные. Spring Boot / PostgreSQL разрабатываются
другим участником отдельно и пока не интегрированы. Авторизация, покупка,
бронирование и отправка партнёрских заявок недоступны.
