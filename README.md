# DamTap

Учебный фронтенд маркетплейса остатков еды со скидкой в Астане.
Next.js App Router, React, TypeScript, Tailwind v4, Nunito и Caveat.

## Запуск и проверки

```bash
npm install
npm run dev
npm run lint
npm run build
npm start
```

Production-сборка использует Webpack. Шрифты загружаются через `next/font/google`;
при первой сборке нужен доступ к Google Fonts.

## Главная страница

Компоненты находятся в `components/`, токены — в `app/globals.css`.
Поиск проверяет названия блюд и заведений; категории фильтруют моковые предложения.
Кнопка «Смотреть все» открывает все 8 предложений в прокручиваемой ленте.
Сортировка по расстоянию, цене, сроку и размеру скидки применяется ко всем найденным
предложениям, в том числе до раскрытия ленты. Счётчик показывает число видимых
карточек и общее число совпадений; сброс очищает поиск, фильтры и сортировку.
Избранное сохраняется в localStorage текущего браузера. Карточка открывает детали,
вход и заявка партнёра показывают демо-состояния, данные никуда не отправляются.
На телефоне есть нижняя навигация и горизонтальная прокрутка категорий и карточек.

В `data/offers.ts` цены указаны в тенге. `getOffers()` вычисляет сроки при запросе
страницы; таймеры на клиенте отсчитываются от `endsAt` каждую секунду и останавливаются
на нуле. Страница динамическая, поэтому даты не фиксируются во время сборки.

## Изображения

Готовые WebP находятся в `public/images`, качество 85; hero — исходные 2100 × 403.
Пак 1: hero, step-1 (парень), step-2 (девушка), step-3 (Земля), business-banner,
leaves-tl и семь category-*. У step-1/2/3 очищены зелёные полупрозрачные края;
у leaves-tl удалён светлый фон. Категории обрезаны до основного значка,
чтобы убрать фрагменты соседних иконок. Общий лист и greenscreen-дубли не публикуются.

Пак 2, webp_800: food-1 — круассан, food-2 — боул, food-3 — том ям,
food-4 — суши, food-5 — красный бархат. Предложения 6–8 временно повторяют фото 1–3.

Исходные паки, `design/` и `AGENTS.md` остаются локальными: исключения заданы
в `.git/info/exclude` (этот файл не передаётся при клонировании).
Макет — `design/mockup.png`. Иллюстрации паков отличаются от деталей макета;
мелкие декоративные надписи намеренно не воспроизводятся.
